# Net2App V5 — Billing Platform (VOS3000)

Modern HTTPS web dashboard for managing the VOS3000 VoIP switch. Built with Next.js 16, React 19, and Tailwind CSS 4.

## Install

```bash
curl -sSL https://raw.githubusercontent.com/eliasewu/v5/main/vos-billing/install.sh | bash
```

## Uninstall

```bash
curl -sSL https://raw.githubusercontent.com/eliasewu/v5/main/vos-billing/uninstall.sh | bash
```

See `vos-billing/README.md` for the full feature list and VOS3000 base installation.
